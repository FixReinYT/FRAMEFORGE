# FRAMEFORGE

**FRAMEFORGE** — редактор покадровой 2D-анимации и цифрового рисования под Windows.

**Создатель:** TheLucassDen

## Версия 0.3.0

### Рисование
- Карандаш, кисть, аэрограф и ластик
- Линия, прямоугольник и эллипс
- Заливка и пипетка
- Настройка размера и непрозрачности
- Выбор цвета

### Холст и история
- Шаблоны: 512×512, 1024×1024, HD, Full HD, 4K, портретный и A4
- Пользовательские размеры от 1 до 8192 px
- Прозрачный или белый фон
- Отмена Ctrl+Z и повтор Ctrl+U (также Ctrl+Y)

### Анимация и экспорт
- Добавление, дублирование, удаление и выбор кадров
- Предпросмотр с настройкой FPS
- Onion Skin предыдущего кадра
- Экспорт кадра в PNG, анимации в GIF
- Экспорт PNG Sequence в ZIP
- Экспорт Sprite Sheet в PNG
- Формат проекта .ffg

### Горячие клавиши
- Ctrl+N — новый холст
- Ctrl+O — открыть
- Ctrl+S — сохранить
- Ctrl+Z — отменить
- Ctrl+U / Ctrl+Y — повторить
- Space — воспроизведение

## Сборка Windows EXE
GitHub Actions собирает приложение автоматически при каждом push в main.
Откройте **Actions → Build FRAMEFORGE for Windows → последний успешный запуск → Artifacts → FRAMEFORGE-Windows**.

Платформа: Windows 10 / Windows 11. Зависимости: Python 3.12+, Pillow.
