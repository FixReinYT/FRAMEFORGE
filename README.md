# FRAMEFORGE

**FRAMEFORGE** — настольный редактор цифрового рисования и покадровой 2D-анимации под Windows.

**Создатель:** TheLucassDen

## Версия 0.9.0

### Интерфейс и навигация
- Полноэкранный режим по F11, выход по Escape
- Изменяемое окно Windows
- Масштабирование холста колесом мыши от положения курсора (10–800%)
- Перемещение увеличенного холста средней кнопкой мыши
- Палитра из готовых цветов и системный выбор цвета

### Рисование
- Карандаш, кисть, аэрограф, ластик
- Линия, прямоугольник, эллипс, треугольник
- Заливка и пипетка
- Настройка размера и непрозрачности кисти
- Вставка PNG, JPG, BMP, GIF и WebP в активный кадр (центрирование; крупные изображения уменьшаются до размера холста)

### Холст и история
- Шаблоны 512×512, 1024×1024, HD, Full HD, 4K, портретный и A4
- Пользовательские размеры до 8192×8192 px
- Прозрачный или белый фон
- Ctrl+Z — отменить, Ctrl+U / Ctrl+Y — повторить

### Анимация и экспорт
- Добавление, дублирование, удаление и выбор кадров
- Предпросмотр с настройкой FPS и Onion Skin
- Экспорт PNG, GIF, PNG Sequence (ZIP), Sprite Sheet
- Формат проекта .ffg

### Горячие клавиши
- Ctrl+N — новый холст
- Ctrl+O — открыть проект
- Ctrl+S — сохранить
- Ctrl+Z — отменить
- Ctrl+U / Ctrl+Y — повторить
- Space — воспроизведение
- F11 — полноэкранный режим
- Escape — выйти из полноэкранного режима

## Сборка Windows EXE
GitHub Actions собирает приложение автоматически при каждом push в main.
Откройте **Actions → последний успешный запуск → Artifacts → FRAMEFORGE-Windows**.

Платформа: Windows 10 / Windows 11. Зависимости: Python 3.12+, Pillow.

## Официальный сайт
Исходники сайта находятся в папке `docs/`.
Чтобы опубликовать сайт через GitHub Pages:
1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/docs`, затем нажмите **Save**.
4. После публикации сайт будет доступен по адресу: https://fixreinyt.github.io/FRAMEFORGE/
