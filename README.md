# FRAMEFORGE

**FRAMEFORGE 0.11.0** — настольный редактор цифрового рисования и покадровой 2D-анимации. Создатель: **TheLucassDen**.

## Что добавлено в 0.11.0

### Фирменная функция — Continuity Threads («Нити непрерывности»)
- Создавай именованные ориентиры персонажа: глаз, кисть, центр головы, кончик предмета.
- Отмечай одну и ту же точку на разных кадрах.
- FRAMEFORGE показывает цветную траекторию и текущую отметку поверх холста.
- Метки автоматически сдвигаются при вставке, дублировании и удалении кадров.
- Данные сохраняются в FFG, учитываются в Undo/Redo и не меняют пиксели рисунка.

### Новый маскот — Флик
- Оригинальный асимметричный персонаж из формы сложенной рамки с бирюзовой палитрой и коралловой складкой.
- Векторная отрисовка в заставке, главном меню, Academy, пустом холсте и строке состояния.
- Иконка приложения использует тот же дизайн-концепт.

### Аккаунты
- Регистрация с уникальным логином, email и отображаемым именем.
- Вход по логину или email, выход, локальная сессия с ограниченным сроком действия.
- Пароли и коды восстановления хранятся как PBKDF2-HMAC-SHA256 хеши с солью.
- Восстановление пароля по одноразовому коду, выдаваемому при регистрации и после сброса.
- Редактирование отображаемого имени и загрузка аватара с нормализацией до 256×256.
- Аккаунт локальный для данного компьютера. Email пока не подтверждается письмом; синхронизации и облачной авторизации нет.
- Регистрация необязательна: редактор и локальные проекты доступны без входа.

### FRAMEFORGE PRO
- Реализован пакет дополнительных фильтров: Glow, Duotone и Film Grain.
- Фильтры встроены в меню «Изображение → Фильтры FRAMEFORGE PRO» и проверяют entitlement перед применением.
- Бесплатная версия сохраняет кисти, слои, выделение, трансформацию, импорт, историю и обычный экспорт.
- Платёжный провайдер пока не подключён. Покупка и управление подпиской отключены; приложение не имитирует оплату и не выдаёт PRO локальным переключателем.

## Основные возможности редактора
- Рисование: карандаш, кисть, аэрограф, ластик, линия, прямоугольник, эллипс, треугольник, многоугольник, кривая Безье, текст, лассо, волшебная палочка, выделение, перемещение, трансформация, заливка, градиент, размытие, резкость, штамп, симметрия и пипетка.
- Слои, кадры, Onion Skin, таймлайн, воспроизведение.
- Масштабирование колесом мыши относительно курсора и перемещение холста средней кнопкой.
- FFG — ZIP-контейнер с project.json и PNG каждого слоя, атомарным сохранением и проверкой целостности.
- Экспорт PNG, GIF, PNG Sequence, Sprite Sheet, MP4 и WebM.

## Формат проекта
FFG сохраняется как ZIP-контейнер. Новое поле continuity_tracks необязательно для старых проектов. Проекты предыдущих версий открываются без карты непрерывности.

## Сборка Windows
Требования: Python 3.12+, Pillow, imageio-ffmpeg, PyInstaller.

    python -m pip install -r requirements.txt pyinstaller
    python -m compileall -q lucas_animator tests
    python -m unittest discover -s tests -v
    python tools/create_icon.py
    pyinstaller --noconfirm --clean --onefile --windowed --icon assets/frameforge.ico --collect-all imageio_ffmpeg --add-data "assets/frameforge_icon.png;assets" --name FRAMEFORGE lucas_animator/app.py

GitHub Actions выполняет регрессионные тесты и собирает Windows EXE при push в main.

## Ограничения текущего релиза
- Проверенная целевая сборка — Windows. macOS/Linux и графические планшеты требуют отдельного CI и ручного тестирования на соответствующем оборудовании.
- Локальные аккаунты не являются глобальными сетевыми аккаунтами.
- Восстановление пароля выполняется по коду восстановления, а не через email.
- Оплата FRAMEFORGE PRO и облачные функции не включены до подключения реального провайдера.
