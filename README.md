# FRAMEFORGE

**FRAMEFORGE** — настольный редактор для создания покадровой 2D-анимации под Windows.

**Создатель:** TheLucassDen

## Версия 0.2.0

### Возможности
- Холст 1280×720 с прозрачным фоном и шахматной индикацией прозрачности
- Кисть, ластик, выбор цвета и размера
- Покадровый таймлайн: добавление, дублирование, удаление и выбор кадров
- Onion Skin предыдущего кадра
- Предпросмотр анимации с настройкой FPS
- Сохранение и открытие проектов `.ffg`
- Экспорт текущего кадра в PNG и анимации в GIF
- Горячие клавиши: Ctrl+N — новый проект, Ctrl+O — открыть, Ctrl+S — сохранить, Space — воспроизведение

### Интерфейс
Обновлённая тёмная рабочая среда: панель инструментов слева, центральный холст, настройки анимации справа и таймлайн внизу.

## Сборка Windows EXE

GitHub Actions собирает приложение на облачном Windows runner. Запуск: **Actions → Build FRAMEFORGE for Windows → Run workflow**. Результат появится в Artifacts под именем **FRAMEFORGE-Windows**.

## Платформа
Windows 10 / Windows 11

Зависимости: Python 3.12+, Pillow.
