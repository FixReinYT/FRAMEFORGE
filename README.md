# FRAMEFORGE

**FRAMEFORGE** — самостоятельный редактор для создания покадровой 2D-анимации в Windows.

## Автор проекта

**Создатель и автор проекта:** [TheLucassDen](https://www.youtube.com/@TheLucassDen)

FRAMEFORGE разрабатывается как независимый программный продукт. Проект не является частью другого канала или приложения.

## О проекте

Цель FRAMEFORGE — предоставить художникам удобную рабочую среду для рисования и создания покадровой анимации: холст, инструменты рисования, таймлайн, кадры, Onion Skin, звук и экспорт готовых работ.

## Текущий статус

Проект находится на ранней стадии разработки. Первая версия прототипа включает базовый холст, кисть, ластик, управление кадрами, воспроизведение анимации, сохранение проектов и экспорт PNG/GIF.

## Платформа

- Windows 10 / Windows 11
